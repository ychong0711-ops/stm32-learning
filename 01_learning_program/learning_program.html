🧮 임베디드 계산기

  
BSP 코드가 내부에서 수행하는 계산을 직접 체험합니다. ① 타이머 ARR(bsp_pwm.c) · ② CAN 비트타이밍(bsp_can.c) · ③ IWDG 타임아웃(bsp_iwdg.c) · ④ ADC 변환(bsp_adc.c) · ⑤ UART BRR(bsp_uart.c) · ⑥ PWM 듀티 변환.


  

    

      
① 타이머/PWM — ARR·프리스케일러

      
freq = clk / ((PSC+1)·(ARR+1)) — bsp_pwm.c 의 PWM_Init 과 동일

      
      
      
      
      
      

    


    

      
② CAN 비트타이밍 — 프리스케일러·샘플포인트

      
prescaler = PCLK1 / (baud·(1+BS1+BS2)) — bsp_can.c 의 prvCanSetTiming

      
      
      
      
      
      

        
        
      

      
      

    


    

      
③ IWDG 타임아웃 — 분주·리로드

      
timeout(ms) = prescaler·(reload+1) / LSI(kHz) — bsp_iwdg.c 의 IWDG_Init

      
      
      
      
      
      
      
      

    


    

      
④ ADC 변환 — 카운트 ↔ 전압

      
12bit: V = counts·Vref/4096 — bsp_adc.c 의 ADC_ReadChannel

      
      
      
      
      
      
      

    


    

      
⑤ UART BRR — 보레이트 오차

      
USARTDIV = APB / (16·baud) — bsp_uart.c 의 UART_Init

      
      
      
      
      
      

    


    

      
⑥ PWM 듀티 변환 — % ↔ 퍼밀 ↔ CCR

      
CCR = ARR·duty/100 — bsp_pwm.c 의 PWM_SetDuty (단위: 0~1000 퍼밀)

      
      
      
      
      
      

    

  







  
🧪 가상 레지스터 시뮬레이터

📦 프로젝트 로드 (임베디드 전용 범용화)

  
manifest.json 번들 포맷으로 다른 STM32F4·FreeRTOS·C 프로젝트를 이 프로그램에 로드합니다. 파일·학습 경로·퀴즈·미션·RTA 태스크가 모두 교체됩니다.

  

    

      
① 샘플 번들 (1클릭)

      
다른 프로젝트(온도 경보 시스템)가 로드되는 것을 확인하세요.

      
      
    

    

      
② 소스 파일 직접 로드

      
내 .c/.h 파일 여러 개를 선택하면 코드 학습 탭의 파일 목록이 교체됩니다. (학습 콘텐츠는 유지)

      
    

    

      
③ manifest.json 로드

      
전체 번들(파일+경로+퀴즈+미션+RTA)을 한 번에. 파일 업로드 또는 직접 붙여넣기.

      
      
      
    

  

  

  

    
manifest.json 스키마 (요약)

    
{
  "title": "프로젝트명",
  "files":  [ { "path": "src/x.c", "content": "...(소스 전문)..." } ],
  "notes":  { "src/x.c": "파일 설명" },
  "path":   [ { "id":"M1","t":"제목","goal":"...","concept":["..."],
               "reads":[{"file":"src/x.c","line":5,"fn":"f","why":"..."}], "activity":"..." } ],
  "quiz":    [ { "m":"M1","q":"문제","o":["선택지..."],"a":0,"w":"해설" } ],
  "subquiz": [ { "m":"M1","q":"주관식","a":["정답","동의어"],"hint":"힌트" } ],
  "missions":[ { "id":1,"t":"제목","lv":"쉬움","learn":"...","marker":"/* ... */",
                "must":"필수코드","hint":"힌트","template":"...(빈칸 포함)...","solution":"..." } ],
  "rta":     [ { "name":"T","T":10,"C":1,"p":3,"D":10 } ]
}
